# Разбор диалогов ZEN TALK — как это работает

Файл для Артура и для Клода в будущих чатах.

## Что собирается

Обезличенно, на устройстве человека:

| Поле | Что это | Пример |
|---|---|---|
| `q` | текст вопроса, очищенный | «Меня зовут [имя], не могу уснуть» |
| `tp` | тема | `сон`, `кофе`, `еда/сахар`, `стресс` |
| `a` | первые 120 знаков ответа банки | чтобы понять, что чинить |
| `r` | оценка: 1 👍 / 0 👎 / null | нажал ли человек оценку |
| `e` | событие | «вышел по кнопке», «опрос пройден: light» |

**Не собирается:** имена, телефоны, почты, ники, ссылки, длинные числа, id людей. Всё вырезается функцией `scrub()` в [app/learn.js](app/learn.js) ДО записи.

Людям об этом сказано в приветствии чата.

## Как посмотреть данные

### Со своего телефона/компьютера
Открыть сайт → консоль браузера → `dzenLearnPeek()`.
Отключить сбор на своём устройстве: `dzenLearnOff()`.

### Со всех устройств (нужна настройка, 5 минут)

Пока данные копятся только локально и никуда не уходят. Чтобы они приходили Артуру:

1. В Telegram открыть **@BotFather** → `/newbot` → имя любое (например «DZEN логи»).
2. BotFather пришлёт токен вида `12345:AAF...`.
3. Написать этому новому боту любое сообщение (иначе он не сможет писать первым).
4. Узнать свой chat id: открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — там будет `"chat":{"id":123456}`.
5. Прислать Клоду токен и id — он допишет одну строку в `index.html`:
   ```html
   <script>window.DZEN_LOG={bot:'ТОКЕН',chat:'ID'};</script>
   ```

После этого раз в сутки с каждого устройства будет приходить сводка в Telegram.

**Про безопасность:** токен такого бота лежит в коде сайта и виден. В худшем случае злоумышленник сможет писать сообщения от имени этого бота — и всё. Ни GitHub, ни деньги, ни данные людей, ни основной бот напоминаний (@dzen_energy_bot) не затрагиваются. Поэтому нужен ОТДЕЛЬНЫЙ бот, а не основной.

## Как по этим данным улучшать чат

Это и есть «обучение»: сама нейронка чужая и её веса менять нельзя, но можно править то, что она получает на вход. Порядок работы:

1. Собрать сводки за период.
2. Найти вопросы с оценкой 👎 и темы, где их больше всего.
3. По каждой такой теме — дописать блок в [app/kb.js](app/kb.js) (база знаний) или правило в промпт в [app/core.js](app/core.js).
4. Если тема повторяется часто, а нейронка отвечает плохо — добавить готовый ответ в `FAQ` в core.js.
5. Прогнать диалоги-тесты заново и опубликовать.

Сценарий проверки лежит в скрипте `dialogs.py` (см. историю чата) — 6 типов диалогов: прощания, невнятные реплики, офтоп, агрессия, длинный рассказ, медицинский риск.

## Важные ограничения, которые уже поймали

- **Лимит Groq: 8000 токенов в минуту.** Поэтому база знаний уходит в промпт кусками по теме (`pickKB`), а не целиком. Если снова начнутся ответы «думаю медленнее обычного» — смотреть в первую очередь сюда.
- **«Пока» многозначно** («пока что не очень») — закрывает диалог только как отдельная реплика.
- **Диалог обязан заканчиваться:** кнопка «Спасибо, достаточно» + распознавание прощаний словами + запрет вопросов в прощальной реплике.
